# Sources and acknowledgements

## Code

- `index.html`, `style.css`, and `sketch.js` are an AI-assisted learning example generated with ChatGPT for the Sound Garden concept. The student should record their own changes and acknowledge assistance according to the module's rules.
- Core implementation: p5.js variables, arrays, loops, drawing functions, mouse input, p5.sound playback, and amplitude analysis.

## Audio

`beat.mp3` is a newly synthesised 9.6-second instrumental test loop, generated programmatically with AI assistance for this example. It contains synthesized tones and percussion, with no vocals, sampled recordings or intentional quotation of an existing song. It is not a Japanese song.

Replace it with your own permitted Japanese-language audio file to develop your chosen concept. Changing a track's displayed title does not replace its audio: replace the MP3 file as well. Record the actual song title, artist and source in your submission, and use audio suitable for the intended distribution.

## Visuals

The flowers are drawn in code from circles, ellipses and straight lines. No downloaded images, image-generation assets or external fonts are used.
